# Fortnite Shorts — Remotion cloud test

A 40-second 1080x1920 30fps placeholder composition for a Fortnite tips Short.

## Render in GitHub Actions
Open Actions > Render Fortnite Short (Remotion) > Run workflow. Download the `fortnite-short-preview` artifact after success.

This first render is a **graphics-only technical test**. It does **not** include licensed Fortnite gameplay, Italian voiceover, subtitles synced to narration, or YouTube upload. These must be added and verified in later steps.

The repository is public: do not commit API keys, OAuth tokens, or private footage.
